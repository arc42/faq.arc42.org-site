{%- comment -%} The left navigation rail — docs.arc42.org's pattern, with faq's A..K categories in place of docs' twelve template sections. Both groups are derived from the pages themselves, so nothing here needs editing when a category or a meta page is added: Categories every page whose permalink starts with /category_, in `order`. The rail label is split out of the page title ("A - General questions" → "A" + "General questions") so the letter can sit in its own column and the labels line up. WP-E replaces the ten hand-written category pages with generated ones driven by _data/categories.yml; when it does, this loop should read that file instead — the markup below does not have to change. More every other listed page (`hide: true` opts out), in `order`. Home is intentionally absent: the masthead logo and wordmark are the link home on every page. The rail is NOT rendered on /home/ — see _layouts/default.html. Mobile: the markup for the toggle is here, the behaviour is still the jQuery handler in assets/js/script.js, whose contract is exactly .nav-toggle[data-target] toggles .active on itself and on the target. WP-D rewrites that file vanilla; keeping the contract unchanged here means WP-D can do so without touching this include. {%- endcomment -%}
